# Dataset

The training data is not included in this repository.

- **File expected by the notebook and `train_model.py`:** `loan_sanction_train.csv`
- **Dataset:** the public "Loan Prediction Problem" dataset (614 rows, 13 columns), widely shared via Analytics Vidhya and Kaggle
- **Columns:** Loan_ID, Gender, Married, Dependents, Education, Self_Employed, ApplicantIncome, CoapplicantIncome, LoanAmount, Loan_Amount_Term, Credit_History, Property_Area, Loan_Status

Download it and place it in this folder as `data/loan_sanction_train.csv`.
